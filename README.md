# ThinkBigJoe

Joe Sardella's AI web-design + automation agency — this repo is the command center
(`/command/**`) and claimed-site portal (`/portal/**`).

**Start here:** [`AGENTS.md`](AGENTS.md) (the ecosystem map + working rules) and
[`docs/README.md`](docs/README.md) (the full documentation index — every doc, every README in
the ecosystem, and when to read which).

## Local dev

```bash
pnpm install
pnpm dev       # http://localhost:3000
pnpm run build # tsc + Next build — the merge gate, run before every push
```
